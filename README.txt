THE GREAT WEB — BUILD 002
=========================
1. Extract this ZIP.
2. Open index.html to preview locally.
3. To publish, upload all six .html files plus style.css and script.js
   into the ROOT of your GitHub Pages repository.
4. In GitHub Pages, use Deploy from a branch / main / (root).

IMPORTANT:
- To receive prepared suggestion emails, set SUGGEST_EMAIL in script.js.
  A mailto link opens the visitor's email app; it does not send automatically.
- Set CHEZE's real website URL in the websites array in script.js.
- Web City is an interactive 2D preview, NOT a full 3D map yet.
- Fonts load from Google Fonts when connected to the internet.
- Do not delete the other HTML pages; navigation relies on all six.
